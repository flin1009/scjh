# 獅甲國中 國中會考歷屆題庫與自製解題技巧講義網 (SCJH CAP Hub)

> 專為國中教育會考（CAP）應屆考生、指導教師打造的**歷屆會考題庫全收錄平台**與**自製「5B 衝 A」解題技巧實戰講義**系統。

---

## 📌 專案簡介

本專案旨在提供全方位、系統化的國三會考備考資源。有別於坊間單純題目的考古題本，本庫深度結合**國立臺灣師範大學心理與教育測驗研究發展中心（心測中心 RCPET）**官方權威數據，並自主研發**自製解題技巧講義**，聚焦協助位於「基礎 5B」的學生精準找出失分盲點，掌握各科題眼與秒殺思維，穩健躍升至「精熟 A / A+ / A++」！

### 🎯 核心目標
1. **歷屆會考題庫全收錄**：完整彙整 111 ～ 115 年（108 課綱最新歷年）全科試題卷、官方解答、試題深度分析與各科答對題數等級對照表。
2. **自製「5B 衝 A」名師秒殺技巧講義**：獨創「題眼圈選 ✕ 名師秒殺招」與「5B 盲點與避坑警訊」，針對每題逐一破解。
3. **官方大數據結合**：標註全卷各題心測中心官方「通過率 ($P$ 值)」與「鑑別度 ($D$ 值)」，讓考生一眼看出高投報率的送分題與衝 A 勝負關鍵題。
4. **國三進度與課表管理**：整合全學期 21 週複習小考日程表、會考倒數計時與 Google/Apple 行事曆匯入支援。

## 💡 自製「5B 衝 A」講義獨創系統

每份自製講義均依據 A4 雙欄專業試卷規格編排（支援網頁即時互動練習與高解析 A4 列印），內建四大核心解題模組：

### 1. ⚡【題眼圈選 ✕ 名師秒殺招】
- 杜絕死背詳解，直接教學生在題幹中「圈出題眼」。
- 傳授名師速解思維（如：代入排除法、極值檢驗法、時序定位法、圖表交集法），讓學生在 30 秒內看穿出題脈絡。

### 2. ⚠️【5B 盲點與避坑警訊】
- 針對 5B 考生最容易落入的誘答選項（如：主觀過度推論、單位陷阱、時空混淆、文字遊戲）提出紅色警訊。
- 點出「為什麼這個選項看似合理卻是錯的」，徹底根治常錯觀念。

### 3. 🎯【算牌矩陣 ✕ 官方通過率與鑑別度】
依據心測中心官方統計數據，將試題劃分四大難度戰略等級：
- **★☆☆☆ 穩賺基本盤 ($P \ge 75\%$)**：秒殺基本題，細心圈題眼，確保 100% 答對率。
- **★★☆☆ 進階核心題 ($60\% \le P < 75\%$)**：考查單一核心概念或圖表推論，熟練公式與圖解法。
- **★★★☆ 衝 A 勝負題 ($45\% \le P < 60\%$)**：跨單元整合或多步驟計算，**5B 躍升精熟 A 的關鍵主戰場**！
- **★★★★ 高鑑別挑戰題 ($P < 45\%$)**：長篇素養或高階難題，優先排除不可能選項，爭取 A++。

### 4. 📝【草稿推導區與自我檢核】
- 左側模擬卷設有充裕的「草稿與推導區」，鼓勵動筆列式畫圖。
- 設有「觀念不清、粗心計算、題意誤解」自我糾錯核取方塊，落實訂正反思。

## 🚀 快速開始與使用方式

### 1. 本地啟動與線上瀏覽
本專案為純靜態現代化 Web 應用，無需安裝複雜後端或資料庫：
- **方式一（直接開啟）**：使用任何現代瀏覽器（Chrome、Edge、Safari、Firefox）直接雙擊開啟 `index.html`。
- **方式二（本地伺服器）**：
  ```bash
  # 使用 Python 啟動本機伺服器
  python -m http.server 8000
  ```
  於瀏覽器開啟 `http://localhost:8000` 即可流暢瀏覽。

### 2. 🖨️ A4 講義列印技巧（最佳列印設定）
本講義採用專業列印 CSS (`@media print`) 排版設計，若需輸出實體紙本講義：
1. 在瀏覽器開啟任一份講義頁面（如 `exams/115/handouts/math.html`）。
2. 按下鍵盤快捷鍵 `Ctrl + P`（Mac 為 `Cmd + P`）開啟列印視窗。
3. **重要列印設定**：
   - **目的地**：選擇「另存為 PDF」或實體印表機。
   - **紙張大小**：`A4`。
   - **方向**：`直向 (Portrait)`。
   - **邊界**：`無 (None)` 或 `最小值`（講義已自帶精確邊界設計）。
   - **選項勾選**：**請務必勾選「背景圖形 (Background graphics)」**，以確保彩色標籤、難度星級與破題框線完整印出。

## 📊 歷屆答對題數等級對照（5B 衝 A 門檻參考）

全站整合了心測中心發布之等級加標示與答對題數對照表，考生可隨時在首頁或年度頁面中查詢各年度各科的「精熟 (A)」、「基礎 (B)」、「待加強 (C)」答對題數切點：
- **國文**：滿分 42 題，A 門檻約 36～37 題（容錯約 5～6 題）。
- **英語**：閱讀 43 題＋聽力 21 題加權計分，A 門檻加權成績約 88.29 分。
- **數學**：選擇 25 題＋非選 6 分加權計分，A 門檻加權成績約 76.20～80.00 分。
- **自然**：滿分 50 題，A 門檻約 43～44 題（容錯約 6～7 題）。
- **社會**：滿分 54 題，A 門檻約 47～48 題（容錯約 6～7 題）。
