## 📌 專案簡介 (Overview)

本專案旨在提供全台灣最完整、系統化且完全免費開源的國中教育會考備考資源。有別於坊間單純題目的考古題解答本，本庫深度整合**教育部**與**國立臺灣師範大學心理與教育測驗研究發展中心（心測中心 RCPET）**官方權威數據，並自主研發**自製解題技巧講義**，聚焦協助處於「基礎 5B」的學生精準找出失分盲點，掌握各科「題眼」與「秒殺思維」，穩健躍升至「精熟 A / A+ / A++」！

### 🎯 核心目標與特色
1. **歷屆會考題庫全收錄**：完整收錄 **111 年至 115 年（108 課綱最新歷年）** 全 6 大考科之官方高清原卷、標準答案、深度分析與各科答對題數等級對照表。
2. **獨家「雙冊分裝版」架構**：
   - **前半冊【第一冊・實戰試題本】**：100% 抽離答案，保留完整題圖與草稿區，提供逼真考場計時模擬。
   - **後半冊【第二冊・名師詳解冊】**：首頁配備 **「⚡ 全卷快速對答案簡表（Quick Answer Key）」**，1 分鐘快速對答案，後續附名師秒殺招與 5B 盲點警訊。
   - **可獨立拆裝**：雙冊自帶獨立封面、獨立連續頁碼，實體列印可從中線乾淨拆卸裝訂成兩本作業冊。
3. **官方大數據結合**：標註全卷各題心測中心官方「通過率 ($P$ 值)」與「鑑別度 ($D$ 值)」，一眼鎖定高投報率的送分題與衝 A 勝負關鍵題。
4. **國三進度與課表管理**：整合全學期 21 週複習小考日程表、會考倒數計時與 Google/Apple 行事曆匯入（iCal）支援。

## 💡 自製「5B 衝 A 雙冊分裝版」講義獨創系統

每份自製講義均依據 A4 專業規格編排（支援網頁即時互動練習與高解析 A4 紙本列印），內建四大核心模組：

### 1. ⚡【全卷快速對答案簡表（Quick Answer Key）】
- 位於第二冊（詳解本）首頁扉頁，以 10 題為一組，清楚呈現題號與藍色粗體標準答案。
- 數學科特別增設【非選擇題官方核心解答速查】（各小題精確數值、幾何證明結論）。
- 附帶當年度心測中心官方「精熟 A / 基礎 B / 待加強 C」門檻題數與加權分參考。

### 2. ⚡【題眼圈選 ✕ 名師秒殺招】
- 杜絕死背詳解，直接教導學生在長篇情境題中「圈出題眼核心關鍵字」。
- 傳授名師速解技巧（如：代入排除法、極值檢驗法、時序定位法、圖表交集法），30 秒看穿出題脈絡。

### 3. ⚠️【5B 盲點與避坑警訊】
- 針對 5B 考生最容易失分的誘答陷阱（如：主觀過度推論、單位陷阱、時空混淆、文字遊戲）提出紅色警訊。
- 點出「為什麼這個選項看似合理卻是錯的」，徹底根治盲點。

### 4. 🎯【算牌矩陣 ✕ 官方通過率與鑑別度】
依據心測中心官方統計數據，將試題劃分四大難度戰略等級：
- **★☆☆☆ 穩賺基本盤 ($P \ge 75\%$)**：秒殺基本題，細心圈題眼，確保 100% 答對率。
- **★★☆☆ 進階核心題 ($60\% \le P < 75\%$)**：考查單一核心概念或圖表推論，熟練公式與圖解法。
- **★★★☆ 衝 A 勝負題 ($45\% \le P < 60\%$)**：跨單元整合或多步驟計算，**5B 躍升精熟 A 的關鍵主戰場**！
- **★★★★ 高鑑別挑戰題 ($P < 45\%$)**：長篇素養或高階難題，優先排除不可能選項，爭取 A++。

## 🖨️ A4 實體講義列印 SOP（完美無跑版）

本講義全面採用高規格列印 CSS (`@media print`) 排版設計，並於第一冊與第二冊銜接處設定自動分頁（`page-break-before: always`）：

1. 在瀏覽器中開啟任一份科目講義（例如 `exams/115/handouts/chinese.html`）。
2. 按下鍵盤快捷鍵 `Ctrl + P`（macOS 請按 `Cmd + P`）開啟列印設定視窗。
3. **重要列印參數設定**：
   - **目的地**：選擇實體印表機或「另存為 PDF」。
   - **紙張大小**：`A4`。
   - **方向**：`直向 (Portrait)`。
   - **邊界**：`無 (None)` 或 `最小值 (Minimum)`（講義已預留精準 10mm 邊界）。
   - **關鍵勾選**：**請務必勾選「背景圖形 (Background graphics)」**，以確保彩色標籤、難度星級與破題框線完整印出。
4. **裝訂技巧**：整份雙面列印完成後，可直接從中央分冊扉頁拆分，用訂書機裝訂成「前半冊：試題本」與「後半冊：詳解本」兩冊！

## ❓ 常見問題（FAQ）

### Q1: 本站收錄的試題與答案出處為何？是否具有權威性？
本站所有歷屆試題卷、官方標準答案、各題通過率（$P$ 值）與鑑別度（$D$ 值）均 100% 同步對齊**國立臺灣師範大學心理與教育測驗研究發展中心（心測中心 RCPET）**公告之官方資料，確保數據精確無誤。

### Q2: 什麼是「雙冊分裝版」？對學生備考有何好處？
傳統坊間講義常為「左頁題目、右頁解答」，學生在自我測驗時視線容易不自覺瞥見答案，降低模擬真實度。「雙冊分裝版」將全卷題目完整集中於前半冊，解答與名師解析集中於後半冊，既能進行完全擬真的計時模擬，考後又能用後半冊首頁的速查簡表在 1 分鐘內核對成績，大幅提升訂正效率！

### Q3: 使用手機或平板能正常閱讀與做題嗎？
可以！全站採用 RWD 響應式網頁設計與向量字級優化，無論在桌機、平板或手機螢幕上均能清晰排版瀏覽。頁面頂端更附帶平滑滾動導航，點擊「📝 第一冊：試題本」或「💡 第二冊：詳解本」即可瞬間穿梭雙冊。
