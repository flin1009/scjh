【第 (1) 小題】

答：$\angle CDE$ 的度數為 $120^\circ$。

【第 (2) 小題】
1. 分析四邊形 $ABCE$：
   已知 $\angle A = \angle B = 90^\circ$ 且 $AE = BC = 130\text{ 公分}$。
   因此四邊形 $ABCE$ 為長方形（矩形），對邊相等：
   $CE = AB = 90\text{ 公分}$。
2. 計算 $\triangle CDE$ 中 $D$ 到 $CE$ 的垂直距離：
   在等腰 $\triangle CDE$ 中，$CD = DE$ 且頂角 $\angle CDE = 120^\circ$。
   取 $CE$ 中點為 $K$，則 $DK \perp CE$，且 $DK$ 平分 $\angle CDE$。
   故 $\angle CDK = 60^\circ$，底邊一半 $CK = \frac{90}{2} = 45\text{ 公分}$。
   在 $30^\circ-60^\circ-90^\circ$ 的直角 $\triangle CDK$ 中：
   $DK = \frac{CK}{\sqrt{3}} = \frac{45}{\sqrt{3}} = 15\sqrt{3}\text{ 公分}$。
3. 計算中心點 $D$ 到地毯底邊的垂直距離（邊心距）：
   由圖可知，中心點 $D$ 到沙發邊 $AB$ 的距離為 $DK + AE = 15\sqrt{3} + 130$。
   地毯邊與 $AB$ 平行且相距至少 50 公分，故 $D$ 點到正六邊形地毯該邊中點的垂直距離 $h$ 至少為：
   $h = (15\sqrt{3} + 130) + 50 = 180 + 15\sqrt{3}\text{ 公分}$。
4. 計算正六邊形地毯之邊長：
   設正六邊形地毯的邊長為 $s$。
   正六邊形由六個邊長為 $s$ 的正三角形組成，其中心到邊的距離（正三角形的高）為 $\frac{\sqrt{3}}{2} s$。
   因此：
   $\frac{\sqrt{3}}{2} s = 180 + 15\sqrt{3}$
   $s = \frac{2}{\sqrt{3}} \left(180 + 15\sqrt{3}\right) = \frac{360}{\sqrt{3}} + 30 = 120\sqrt{3} + 30\text{ 公分}$。
答：地毯的邊長至少需要 $30 + 120\sqrt{3}$ 公分（或寫 $120\sqrt{3} + 30$ 公分）。
